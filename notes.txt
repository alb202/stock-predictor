equity_info: contains some fields such as sector and industry that is fixed for a stock but can be linked to the index in etf_info

indicies: says what index each stock is a member of

regression_indicators_ma: smoothed versions of data in regression_indicators
ta__change: provides the relationship of the price at each date going back a certain number of days
ta__ma_ratio: provides the ratios of various moving averages for n different number of days
talib: the calculated indictors for each date from the TALib library
